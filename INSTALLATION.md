# Installation Guide for Mango-Salvania\n\n## Prerequisites\n- Node.js installed (v14 or later)\n- npm or Yarn package manager\n- Expo Go app on your mobile device\n\n## Steps to Install\n1. Clone the repository using: `git clone https://github.com/esoytesoy123-oss/Mango-Salvania.git`\n2. Open a terminal and navigate to the project directory: `cd Mango-Salvania`\n3. Run `npm install` or `yarn` to install dependencies.\n4. Use `npm start` or `yarn start` to run the project.\n5. Scan the QR code displayed in the terminal with the Expo Go app.
